# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик ответа и сам решает, что отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей и ключи не нужны.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

## Тесты

```sh
node --test triage.test.mjs
```

Тест сам запускает сервер на свободном порту. Он проверяет успешный ответ, некорректный ввод и все пять сценариев сбоя имитатора: `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`.

Для ручной проверки в браузере: отправьте «Когда будет доставка?» и убедитесь, что появились тема и черновик. Затем отправьте `[timeout]`: старый черновик должен исчезнуть, а вместо него появиться сообщение о ручном разборе. Поле с заявкой остаётся доступным. При вводе одних пробелов страница просит ввести текст, не отправляя запрос.

## Поведение API

- `400 invalid_input`: битый JSON, отсутствующий, нестроковый или пустой после `trim()` текст.
- `200 ready`: сервер проверил, что тема допустима, а черновик не пуст после `trim()`.
- `200 manual_review`: модель не успела за 300 мс, сообщила об ошибке или вернула неподходящий результат. Тема и черновик возвращаются как `null`.

## Польза для менеджера

Менеджер быстрее разбирает типовые заявки и не принимает старый черновик за новый при сбое; эффект можно измерить по медианному времени на заявку с учётом проверки и правок.
